# Source and distribution policy

Evoker is a source-inspired component library. Public packages contain original TypeScript, React components, CSS geometry and documentation. Applications supply their own content and data.

Extracted game artwork, fonts, native tables, encryption keys, decoder tooling, detailed research evidence and conversation transcripts remain private local material. They are excluded from Git and package archives. No game installation is needed to build or use the library.

Reference research informs composition principles such as independent decorative layers, selection indicators, text and motion. This does not establish exact game runtime fidelity. Native execution, material playback and final screen composition have not been verified.

Git ignore rules prevent routine staging; they do not encrypt local files or prevent deliberate force-add operations. npm packages allow only package metadata and built library outputs.
