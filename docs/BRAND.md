# Evoker identity

The **signal E** is Evoker's official logo. It uses three angular white blades, a cyan motion cut and a blue frame to reflect the library's layered surfaces and independent motion.

- [Mark](../assets/brand/evoker-mark.svg): square icon for the app, favicon and compact placements.
- [Lockup](../assets/brand/evoker-lockup.svg): mark plus a custom geometric Evoker UI wordmark for the README and wider placements.

Both assets are self-contained SVGs with paths, accessible titles and descriptions. They use no raster images, external resources or font dependencies. Their geometry is original; neither asset is extracted from Persona 3 Reload or represents an official game endorsement.

The palette is ink `#303030`, blue `#1269cc`, cyan `#51eefc` and white `#ffffff`. Prefer the supplied proportions and keep clear space around the mark. The dark backing preserves contrast on light and dark surfaces. For a labelled link, give the SVG image an empty `alt` and let the link text provide its accessible name; standalone images need a meaningful alternative.

`assets` is the playground's Vite public directory. The app and documentation use `/brand/evoker-mark.svg`; the HTML favicon points to the same source. Edit these canonical assets rather than maintaining local copies. The source SVGs are covered by the repository's MIT license.
