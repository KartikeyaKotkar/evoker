# Code of conduct

Evoker welcomes contributors with different backgrounds and levels of experience. Help make the repository useful and approachable.

- Give specific, constructive feedback about the work rather than the person.
- Respect different perspectives and accept correction without personal attacks.
- Do not harass, threaten, discriminate against or publish private information about others.
- Keep issues and pull requests relevant to the project. Do not spam or impersonate contributors.

These expectations apply to this repository's issues, pull requests, reviews and other project spaces. Maintainers may edit or remove inappropriate content, close disruptive threads or restrict participation. They should explain moderation decisions when doing so does not expose private information.

For a project-process concern that can be discussed publicly, open an issue without personal or sensitive details. For abuse that should not be posted publicly, use GitHub's **Report abuse** option or [contact GitHub Support](https://support.github.com/contact/report-abuse). Do not repost harmful material to make a report.
