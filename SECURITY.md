# Security reporting

Evoker is in beta. Security fixes target the current `main` branch; older beta snapshots do not have a separate support commitment.

Use [GitHub private vulnerability reporting](https://github.com/K2X-Lab/evoker/security/advisories/new) to report a suspected vulnerability. You can also open the repository's **Security** tab and choose **Report a vulnerability**. Please include the affected commit or package version, a minimal reproduction, expected impact and any suggested mitigation.

Do not disclose an unpatched vulnerability in a public issue or attach credentials, encryption keys, extracted game assets or other private material. If the private reporting option is unavailable, open a public issue requesting a private contact channel without including vulnerability details.

Maintainers will review reports as availability permits. There is no guaranteed response time or bug-bounty program.
